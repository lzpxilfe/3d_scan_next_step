# archphoto (작업 명칭)

**고고학 전용 오픈소스 사진실측 — 검증 가능한 3D 메쉬 생성**

유물(artifact)·유구(feature)·유적(site)을 대상으로, 사진과 측량 자료로부터
3D 메쉬를 만드는 오픈소스 프로그램입니다. 누구나 자유롭게 사용할 수 있습니다.

> **상태: 코드 스캐폴드 단계.** 아직 실행 가능한 복원 알고리즘은 포함되어 있지 않습니다.
> 이 저장소는 요구·데이터 계약·모듈 경계를 코드 형태로 고정한 뼈대입니다.

> **언어 전환 [D-2026-10-12-11]:** 제품 코어와 GUI를 Python에서 **Rust**로 전면 이식했습니다
> (배포 단순성·계약의 컴파일 타임 강제·고속화 코어 성능). `crates/`가 제품 워크스페이스이며,
> `src/archphoto/`(Python)은 계약의 **참조 구현**으로 보존됩니다 — 조용히 삭제하지 않습니다.
> 현재 합성 계약 테스트는 **Rust 81 passed**, **Python 110 passed**입니다.

## 이 프로젝트의 차별점 [사용자 확정]

1. **완전히 새로운 알고리즘** — 기존 상용/오픈소스와 다른 복원 접근을 연구·구현합니다.
2. **고고학 워크플로 특화** — 유물/유구/유적, 관측/보간 표면 구분, 단면·해석선, 실측/전시 모델 구분.
3. **고속 복원** — 카메라 보정·GCP·다중시점 기하를 유지하면서 학습형 깊이, 시점 선택, 국소 정밀화, 증분 융합으로 중복 계산을 줄이는 연구 경로(R01).

## 핵심 원칙 (코드 구조에 반영)

- **원사진·원측량자료를 덮어쓰거나 자동 삭제하지 않는다.**
- **GCP와 독립 검증점을 분리한다.** 검증점은 보정에 사용하지 않는다.
- **좌표계·높이 기준·단위·카메라 변환을 명시한다.**
- **관측 표면 / 보간 표면**, **실측 모델 / 전시 모델**을 구분한다.
- **학습 모델 신뢰도를 실제 치수 오차로 취급하지 않는다.**
- **처리 실행 성공 ≠ 측량 검증 통과.** 상태를 구분해 표시한다.
