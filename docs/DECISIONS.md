## D-2026-10-12-08 — GUI 프레임워크: PySide6 (Qt) + 직접 만든 SVG 아이콘

- **분류:** [D] (사용자 선택, [O]였던 GUI 프레임워크 확정)
- **내용:** GUI는 **PySide6 (Qt)**. 아이콘은 **직접 디자인한 원본 SVG**(`assets/icons/`)로
  만들고 위젯에 결합한다. 3D 메시 뷰포트는 Qt OpenGL 위젯 방향.
- **라이선스 주의 [O]:** PySide6/Qt는 **LGPL-3.0**. Apache-2.0 본체와 **동적 링크**로 결합해야
  하며, 재링크·소스 제공 등 LGPL 의무는 **배포 전에 확인 필요**. Qt 정적 링크·수정 시 의무가
  달라진다. 이를 확인 전에 "Apache-2.0과 문제없음"으로 표시하지 않는다.
- **의존성 영향:** PySide6(Qt 포함)는 수백 MB급 런타임 의존성. 현재 여유 125Gi로 공간은 충분.
- **아이콘:** `assets/icons/*.svg` 8종(원본, 24×24, currentColor). 프레임워크 무관 SVG 원본이라
  Qt(QIcon)·웹·다른 툴에 재사용 가능.
- **실행 기록(2026-10-12, 사용자 승인 후):** 프로젝트 `.venv`에 **PySide6 6.12.0** 설치.
  `tests/test_gui.py`에서 오프스크린으로 MainWindow 생성 + 8개 아이콘의 QIcon 로드 검증
  (**80 passed**). 초판 `ICONS_DIR` 경로 버그(`src/assets` 잘못 계산)는 테스트가 잡아 수정.
  `python -m archphoto.gui`로 창 표시 확인. 단, **툴바 액션은 미연결 스캐폴드**이며
  3D 뷰포트는 플레이스홀더 — 이는 기능 완성이 아니다.
